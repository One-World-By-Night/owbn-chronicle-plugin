# Configurações do C&C

Liga as crônicas e os escritórios de coordenação neste site, e guarda os gêneros e regiões que o editor de crônicas oferece.

## Quem pode usar

Administradores do site.

## Como chegar

wp-admin → **OWBN C&C** → **Settings** (a tela se chama **C&C Plugin Settings**).

## A tela

- Uma nota dizendo que os outros sites da OWbN leem estas fichas pelo gateway do OWBN Core, em `owbn/v1/`.
- **Chronicles** → **Enable Chronicle management** - liga **All Chronicles** e as telas das crônicas.
- **Coordinators** → **Enable Coordinator management** - liga **All Coordinators** e as telas dos escritórios.
- **Genre List** → **Available Genres** - um por linha. Os **Genres** de uma crônica e os gêneros das sessões dela saem daqui.
- **Region List** → **Available Regions** - uma por linha. A **Region** de uma crônica sai daqui.
- **Save Changes**.

## Tarefas comuns

### Acrescentar um gênero ou uma região

1. Ponha-o numa linha só dele em **Available Genres** ou **Available Regions**.
2. Clique em **Save Changes**. O editor de crônicas o oferece na hora.

## Bom saber

- Desligar um tipo esconde as telas dele neste site. As fichas continuam, e voltam quando ele é ligado.
- Tirar um gênero ou uma região de uma lista não o tira das crônicas que o têm.
- A chave e o endereço que os outros sites usam para ler as fichas ficam em **OWBN Core** → **Settings**.

## Solução de problemas

- **Sem All Chronicles ou All Coordinators em OWBN C&C.** O interruptor dele está desligado neste site.
- **Falta um gênero ou uma região no editor de crônicas.** Acrescente-o aqui.
